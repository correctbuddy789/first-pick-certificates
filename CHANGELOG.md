# Changes

## 1.1.0 — 13 October 2026

- Connected imported panels, all seven published binary-answer policies,
  and custom `choose(state)` plug-ins through one batch runner.
- Added exact prefix budgets that stop before the next unaffordable query;
  the existing affordable-selection mode remains available for adaptive policies.
- Verified the shared runner against all 32,256 frozen comparator slots,
  with selected physical-trace and private-ledger equivalence checks.
- Added a matched active-blocker versus exact-relevance experiment on all
  2,304 original cases, holding pick-first and acquisition priority fixed.
- Added descriptive cost strata and deterministically selected win/loss traces.
- Added a six-budget study on all 1,152 binary-answer cases using the public
  runner, preserving initial certificates and reporting all four design/cost strata.
- Preserved all original studies, designs, and their recorded outputs.

## 1.0.0 — 13 October 2026

- Added cost-normalized blockers and a cached-answer/common-stopping
  adaptation of published monotone-DNF round robin.
- Reused all 1,152 binary-answer instances under a separately frozen
  internal design amendment; preserved every original study output.
- Added schema 1.0 for JSON/CSV complete tiers, validated blocker conversion,
  immutable policy callbacks, and recorded certificate outputs.
- Added an explicitly synthetic learning-resource application with 18
  deterministic runs, separate response records, and a custom plug-in.
- Distinguished user budget stops, nonanswers, and unavailable unknowns.
- Fixed decimal parsing so precise/tiny costs and budgets remain exact;
  added independent-world, interface, and boundary verification.
- Included per-run comparisons, verifiers, and deterministic package hashes.
