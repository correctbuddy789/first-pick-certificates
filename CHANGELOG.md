# Changes

## 1.0.0 — 13 October 2026

- Added cost-normalized blockers and a cached-answer/common-stopping
  adaptation of published monotone-DNF round robin.
- Reused all 1,152 binary-answer instances under a separately frozen
  internal design amendment; preserved every original study output.
- Added schema 1.0 for JSON/CSV complete tiers, validated blocker conversion,
  immutable policy callbacks, and recorded certificate outputs.
- Added an explicitly synthetic learning-resource application with 18
  deterministic runs, separate response records, and a custom plug-in.
- Distinguished user budget stops, nonanswers, and unavailable unknowns.
- Fixed decimal parsing so precise/tiny costs and budgets remain exact;
  added independent-world, interface, and boundary verification.
- Included per-run comparisons, verifiers, and deterministic package hashes.
